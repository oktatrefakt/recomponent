# reComponent

## Leírás

Ez egy alkatrész nyilvántartó alkalmazás.

## Feladat

* Refaktorálja a tiszta kód elveinek megfelelően!
* A refaktorálás során nevezze át a refaktorált projektet.
* Az új alkalmazásban jelenítse meg, mi volt az eredeti és ki gyártotta.

Ügyeljen a következőkre:
* Elnevezések
* Megjegyzések
* Behúzások
* Egy felelősség elve
* Metódusok mérete
* Kivételek kezelése

## Mit kell tudnia a programnak?

A prgram be kell kérje egy alkatrész adatait:
- cikkszám
- név
- ár
- készlet

Ezután a program írja ki a képernyőre és fájlba az alkatrész adatait.
Tájékoztasson a fájlbaírás sikeréről.

A program ezt követően írja ki, hogy hány alkatrész van a fájlban.

A program a futás végén írja a képernyőre az összes alkatrészt.
