# Component

## Leírás

Ez egy alkatrész nyilvántartó alkalmazás.

## Feladat

Refaktorálja a tiszta kód elveinek megfelelően!

## Mit kell tudnia a programnak?

A prgram be kell kérje egy alkatrész adatait:
- cikkszám
- név
- ár
- készlet

Ezután a program írja ki a képernyőre és fájlba az alkatrész adatait.
Tájékoztasson a fájlbaírás sikeréről.
